## 經濟部能源署：電力排碳係數

- 公告頁面：<https://www.moeaea.gov.tw/ecw/populace/content/ContentDesc.aspx?menu_id=27028>
- 94 至 113 年度（2005–2024）每年公布一個數值。94 至 109 年度的數值取自 110 年度公告所附的歷年數值表。
- **114 年度（2025）起公布三個數值**，只存在於年度 PDF：
  - 公用售電業 0.467 公斤CO2e/度。官方說明的適用範圍是「檢視公用售電業整體銷售電量之平均電力排碳情形，作為電業管制機關進行管理之依據」。
  - 產業盤查使用 0.466。適用對象為電價種類中之表燈營業、低壓電力、高壓電力、特高壓電力用戶。
  - 表燈非營業、包燈用戶 0.471。「民生住宅」是經濟部商業服務業節能減碳專區對它的稱呼，能源署公告本身沒有用這個詞。
- 開放資料 CSV（data.gov.tw 資料集 8308「能源指標年資料」）只有公用售電業的數列，2025 年是 0.467。只靠 CSV 會給盤查使用者錯的係數，所以 CSV 只用來交叉檢查。CSV 會省略尾端的零（2016 年寫 0.53，PDF 是 0.530）。
- 公告日期：只有 113 年度（2025-04-14）與 114 年度（2026-06-02）在官方頁面上觀察到。其餘年度的公告日期未確認，資料庫中為空值。
- 未確認：年度 PDF 的重製授權；全國電力排放係數（有別於公用售電業電力排碳係數）的官方數值，未收錄。

## 台灣自來水公司與臺北自來水事業處

- 台灣自來水公司：<https://www.water.gov.tw/ch/Subject/Detail/2269?nodeId=813>，CSV <https://www.water.gov.tw/opendata/sale3.csv>（data.gov.tw 資料集 25681）。單位是公斤 **CO2**／度，邊界是該公司的用電與用油除以總供水量。
- 臺北自來水事業處：<https://data.gov.tw/dataset/155475>。單位是公斤／度（CO2e），算法一：（類別1＋類別2）÷ 總配水量。官方另有算法二（類別1至6）的數值只出現在網頁上，未收錄。
- 兩者的服務區域與計算邊界不同，建成不同的係數，不合併。台水的結果（CO2）不與 CO2e 的結果相加。

## 環境部：公告「溫室氣體排放係數」

- 113 年 2 月 5 日，環部授氣字第1139101231號。下載頁面：<https://ghgregistry.moenv.gov.tw/epa_ghg/Downloads/FileDownloads.aspx?Type_ID=1>
- 匯入自 ODS（sha256 `085fe962e158078e5b3383568b4eeeda0466373ae2d0f62f7870efa0a0dcd0b0`），數值與同一公告的 PDF 抽核一致。
- 附表一的燃燒排放係數以低位熱值為基礎，單位 kg/TJ，CO2、CH4、N2O 分列。**官方沒有公布每公升或每公斤的係數，也沒有預設熱值**；ODS 中熱值是事業自行填寫的空白欄位。
- 溫暖化潛勢採附表四（IPCC AR5）：CO2 1、CH4 28、N2O 265。《溫室氣體排放量盤查作業指引 113 年版》的燃燒算例使用 CH4 28。
- 已收錄附表一固定燃燒的全部 53 種燃料，以及移動燃燒的車用汽油（三種控制技術各一筆）、柴油、液化石油氣。
  - 生質燃料 11 種（固體、液體、氣體生質燃料與都市廢棄物的生質部分）另有標記。依《盤查作業指引》，生質燃料燃燒的 CO2 要計算並單獨表列，不計入排放總量；CH4 與 N2O 計入。
  - 固定燃燒表的「液化天然氣」英譯是 Natural Gas Liquids (NGLs)，不是 LNG；移動燃燒表的「液化天然氣」才是 LNG。
- 已收錄附表四含氟氣體的溫暖化潛勢 46 筆（HFCs、PFCs、SF6、NF3 等），用於計算冷媒等逸散。官方標示「<1，僅需定性」的氣體不收。CO2、CH4、N2O 的 GWP 用在燃燒計算，不另列為係數。
- 附表三「冷凍及空調」只提供各類設備逸散率的**範圍**（占初始填充量的百分比／年），例如住宅及商業建築空調運行排放 1–10%、冰水機 2–15%、車輛空調 10–20%。沒有單一預設值，所以年逸散率由使用者提供，服務只指出它是否落在官方範圍內。
- 附表四只列純物質。混合冷媒（R-410A、R-407C 等）以 `refrigerant_blend` 計算：使用者提供各成分的質量百分比，服務依附表四逐成分計算並加總。**服務沒有內建任何冷媒的成分比例**，也不查證使用者給的比例；合計不是 100 就拒絕，不補足也不調整。回應中的加權 GWP 是依使用者的比例算出來的，不是官方公布的數值。
- R-22 與碳氫冷媒不在附表四內，無法計算。
- 未收錄：
  - 附表二製程。它是五個產業的公式與參數（碳酸鹽含碳量、氨氣各製程、鋼鐵、半導體 Tier 2a 的利用率與削減率等），不是可以直接乘活動量的係數，需要各產業專屬的計算流程。
  - 附表三的生活廢水、工業廢水、固體廢棄物。同樣是公式與參數（Bo、MCF、DOC 等）。
  - 移動燃燒的天然氣、乙醇、煤油、潤滑油。CO2 表與 CH4/N2O 表的燃料名稱無法一對一對應。
- 「只涵蓋燃燒階段」是依其引用的 IPCC 燃燒排放係數表推論，公告沒有明文，資料庫中標為 `inferred`。
- 未確認：事業溫室氣體排放量資訊平台檔案的重製授權。「溫室氣體排放係數管理表 6.0.4」在官方下載區找不到，不收錄。

## 環境部：碳足跡排放係數 `CFP_P_02`

- 資料集頁面：<https://data.moenv.gov.tw/dataset/detail/CFP_P_02>，API `https://data.moenv.gov.tw/api/v2/cfp_p_02`。
- **必須帶會員 API Key**。不帶金鑰時回 HTTP 200 與純文字「api_key 不存在。」，所以同步程式檢查的是內容，不是狀態碼。金鑰免費申請，效期一年，每日 5000 次：<https://data.moenv.gov.tw/api-term>
- 文件記載的欄位：`name`、`coe`、`unit`、`departmentname`、`announcementyear`、`scpoe3_iso`、`scpoe3_ghg`（`scpoe` 是來源自己的拼法），全部是文字型別。
- data.gov.tw 上的同名資料集（28176）只是指回這支 API，不是免金鑰的鏡像。
- 這是產品碳足跡係數，不代表適合直接用於組織溫室氣體盤查。「公告年份」不是適用年度，所以不寫入 `reference_year`。
- 2026-11-13 以會員金鑰實測：
  - 回應是最外層的 JSON 陣列，欄位名稱小寫，就是上述七個欄位。共 1,188 筆，數值全部是合法數字，沒有完全重複的列。
  - **沒有紀錄 ID。** 有 13 組（27 筆）的名稱、單位、發布單位、公告年份完全相同而數值不同（例如乙烯有 1.75 與 1.88）。來源沒有提供區分依據，這些紀錄標為僅供查詢。係數 ID 因此是四個欄位加上數值的雜湊；官方更正數值時，會表現為舊係數撤回、新係數出現。
  - 宣告單位有 47 種寫法，形式是「公斤(kg)」「度(kwh)」「延噸公里(tkm)」。能對應到標準單位的可以計算；以件數計的（包、瓶、片、個…）僅供查詢，因為每件產品的碳足跡只對那個產品有意義。
  - 本機同步結果：899 筆可計算、289 筆僅供查詢。
  - 搜尋比對的是官方的係數名稱。查「塑膠原料」找不到名稱不含這幾個字的係數，要查「聚丙烯」這類具體名稱。
- 來源移除的紀錄會標為撤回，不刪除，用過它的計算仍可重現。
